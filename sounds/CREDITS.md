# Rekaman suara alam

File di folder ini diambil dari koleksi suara proyek open-source **Moodist**
(https://github.com/remvze/moodist), yang bersumber dari Freesound dan Pixabay dengan lisensi
**CC0** (domain publik) atau **Pixabay Content License** (bebas dipakai, termasuk di aplikasi,
tanpa atribusi; tidak boleh dijual/dibagikan ulang sebagai file suara lepas).

Untuk MyTube Vault, file-file ini dipotong, kekerasannya disamakan (loudness normalization), dan
dikompres ulang ke MP3 64 kbps (stereo) / 48 kbps (mono).
